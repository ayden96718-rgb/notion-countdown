# AGENTS.md — Codex 项目执行规则

本文件适用于本仓库的所有代码/文档改动。用户的最新明确指令优先。

1. **先读规范，再写代码。** 每次任务开始前必须读取 `docs/requirements.md`、`docs/CODEX_HANDOFF.md` 和相关截图/计时表；不得只凭聊天摘要开发。
2. **前十组为定制规则，不是照搬原应用。** **第1/2组在总首页直接命名「个位数相加」「个位数相减」，不可设置额外「闪电心算」首页；点击后为单数字闪卡、最终一次答题**；第3～5及第8～10组为每题独立算式；第6、7组不计时。强制进借位和题量规则以需求文档为准。
3. **最优先保护既有规则。** 与新需求冲突时先在交付说明中列明；不得因重构删除、稀释、改变已确认需求。
4. **需求改变必须留痕。** 用户明确要求更新时，修改权威 `docs/requirements.md` 并维护变更记录；未确认讨论只记入待定，不实现成硬编码规则。
5. **每次开发必须验收。** 按 `docs/ACCEPTANCE_TESTS.md` 运行及更新自动测试，注明每条规则实现状态。
6. **免费与隐私。** 默认静态网页、本机计算及本地存储；不得引入收费服务。不要将个人成绩上传公开仓库；不要在网页源码内存放密钥。
7. **截图只作参考。** 图片经裁剪且有来源索引；不要直接将第三方应用图片部署为网站视觉资产。优先原创布局，以使用体验为参照。
8. **截图证据高于推测。** 计时以`data/timing-reference.json`中 `count` 对应截图为准；15题、其他自定义题量若没有原始证据，仅可使用明确标注的推算公式。第8～10组未提供15题截图，不要伪称官方数值。**第10组10题采用用户明确指定的42/34/28秒（截图27），例题1588−695不是位数规范。**
9. **限制仓库范围。** 只在本 `susuan-trainer` 仓库内修改。除非用户明确同意，不修改/删除用户其他仓库。
10. **完成时报告差异。** 交付内容包含已实现列表、未实现列表、测试与构建结果、Pages部署步骤、与截图不同之处。
