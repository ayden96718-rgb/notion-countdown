## 第1组（10个个位数加法）

- [x] 每组恰好10个1～9数字、没有0，显著偏向6～9。
- [x] 单次仅显示一个数字，点击整张卡显示下个，不泄露总和/序列。
- [x] 直到第10张完成后才输入总和，答案与10数求和一致。

## 第2组（动态个位借位减法）

- [x] 起始整数动态生成，满足1≤S≤99且非固定100。
- [x] 恰好10个1～9的减数，最终S−sum(d)>0。
- [x] UI恰好1张起始卡+10张减数卡，逐次点击，不显示完整算式。
- [x] 逐步按 `current%10<d` 验算借位，生成器尽量提高借位率且不过度重复9。
- [x] 不承诺10次全借位（数学上不可实现），不可因优化算法出现负数答案。

## 第3组（两位数加法）

- [x] 每题为a+b，两数均10～99。
- [x] 对至少1000题采样验证 `(a%10)+(b%10)>=10` **100%成立**。
- [x] “十几+十几”在N题中不多于 `floor(0.3*N)`（N=10最多3、N=15最多4）。
- [x] 支持10题、15题、自定义N；10题门槛28/22/18，15题42/33/27。

## 第4组（两位数减法）

- [x] 每题为a−b，满足 `10<=b<a<=99`、`a%10<b%10`。
- [x] 对至少1000题采样验证100%借位、最终答案>0。
- [x] 不产生“十几减十几”的负差矛盾题。
- [x] 与第3组题量、计时、输入键盘一致。

## 第5组（两位数加减混合）

- [x] 每题恰有两个两位数与一个加或减符号。
- [x] 所有加法必须个位进位；所有减法必须个位借位且结果>0。
- [x] 加减符号在题组内随机混排；10/15/自定义题量及标准同第3组。
- [x] 加法子题中十几+十几保持不超过30%（精确计数口径等待用户修订）。

## 第6/7组（不计时）

- [x] ×2 与 ÷2 都是两位数输入。
- [x] **没有用时评级、不出现计时成绩标准**。
- [x] 除以2允许奇数，半整数用小数（如18.5）作答，与本轮明确确认一致。

## 第8/9/10组（三位数系列）

- [x] 第8组为三位数相加、第9组为三位数相减、第10组为两种混合。
- [x] 逐题算式输入+数字键盘，不使用闪现数字卡。
- [x] 第8组10题合格40/良好32/优秀26秒；第9组10题38/30/24秒。
- [x] **第10组10题用时按用户最新指定：合格42秒、良好34秒、优秀28秒**；15题/自定义若启用线性推算需注明。
- [x] **第10组每个操作数仍为三位数**，不得因为计时参考截图的`1588−695`把题生成器扩大到四位数。
