## 实现内容

- 十组固定编号和名称；第1、2组在总首页直接开始，无闪电心算中转页。仅逐张展示数字，最后一次答题，完成后回顾10个数字及起始数。
- 第1组固定10个1～9数字，至少7个为6～9，兼顾多样性。第2组在96组多样化候选中逐步计算借位，结合起始数≤99、结果>0筛选，不错误承诺10次全借位。
- 第3、4组每题强制个位进/借位。第5组混排两种运算，分别遵守强制规则；“十几+十几≤30%”按加法子题数保守计算。
- 第6、7组不调用计时器、计时字段为空、训练/结果/历史均不显示用时或评级。第7组允许奇数，支持触屏/实体键盘小数输入。
- 第8～10组每题两个三位数；普通减法采用正差设计，不强制进借位。10题参考分别40/32/26、38/30/24、42/34/28秒。
- 除闪卡外支持10/15/自定义5～100题。第3～5组的10/15题均使用原始确证值；其他扩展题量标明“按比例推算，非原应用截图原值”。
- 屏幕数字键盘、实体键盘、清空、退格、确定、小数、负数（自定义减法）；空值/非法数值不能提交。离开和重开需确认，不保存未完成成绩。
- 闪卡最终结果、有序回顾；算式汇总弹窗、逐题复盘、真实单题及总用时、重来/返回。正确率与用时区间单独呈现，不推断错题综合评级。
- 六个有明确算式及时间证据的扩展练习：三位减两位、两位×一位、三位×一位、两位×11、两位×15、两位×两位。
- 自定义加/减/乘：首数1～4位，后数随机位数/固定数/随机范围，运算符可多选。保留数值范围，自定义减法可产生负数；没有已核实时间门槛，仅记录用时。
- 本地最近100组成绩、设置及最近一次自定义规则；成绩/题目导出。存储被禁用时仍可练习并手动导出；不伪装成云端同步。
- 原创图标、manifest、苹果主屏幕图标、离线缓存与版本隔离。15个静态资产约136KB，无运行依赖。提供独立仓库Actions模板及现有仓库子目录发布器；生产资产来自dist，不上传真实训练数据。

## 实现决策与未实现边界

- 第6、7组题量采用可调整的10/15/5～100题界面，默认10题；这不是用户指定的不可变规则。
- 第5、10组默认加减各半（奇数题量四舍五入），可选约30%/50%/70%加法，顺序随机；精确比例未冒充硬需求。
- 计时从首题显示到最后提交，包含后台及等待；不暂停。用时区间仅作速度参考，不把错题转换成未确认的综合等级。
- 尚未开放：凑整百、多数相加、其他混合形态、扩展除法/整除精度、乘法估算与分数转百分数判分、自定义除法/幂运算、手写笔输入、拖拽键盘、返回修改已交答案、错题单题重做、云同步。待补充原规则；核心十组不受影响。
- 与截图不同：原创品牌与图标；桌面双列训练卡+设置栏，手机双列+下方设置；圆角绿色卡片与固定数字键盘；没有原小程序的难度页、手写/拖拽键盘和上/下题。参考图27四位数示例未复制进第10组生成器。
- 无改动/冲突：未弱化既有十组规则；27张来源截图保留为文档证据，不作为生产网页资产。
