## 你将接手的任务

基于本仓库，使用**完全免费的 GitHub Pages 静态网站**实现用户专用的“行测速算小助手”网页版。核心在于**前十组规则与输入交互完全正确**，其他原应用截图中的算式功能按参考逐步扩展。最终网页兼容 iPhone/iPad Safari 与 Windows 浏览器，支持主屏幕快捷访问。

## 开发优先级

**第一阶段：框架与10组核心训练**

- 创建响应式静态网页（不需要服务器），展示十个训练入口，保留组号。**第1/2组在统一总首页直接显示「个位数相加」「个位数相减」两个入口，不要再套一层「闪电心算」入口。**新图26号为总菜单布局参考。
- 第1、2组使用大卡片点击换数；第2组起始数动态≤99，10次减法后>0，筛选高借位率且题目多样。
- 第3、4、5组使用完整算式+数字键盘；确保第三组每题个位进位、第四组每题个位借位且结果为正、第五组两种硬约束分别满足。
- 第6、7组单独实现×2、÷2且**不计时**；**v2.3已确认奇数÷2用小数（如18.5）作答**。
- 第8、9、10组实现三位数加法/减法/混合，沿用参考页题量、键盘、计时交互。**第10组10题按用户指定的截图27使用42/34/28秒**；注意截图算式`1588−695`只用来确认时间和页面，第10组两个运算数仍须三位数。
- 第3～5组计时准确展示两种确证题量（10/15），其他数量按每题速率推算并标注。
- 首页和答题页面在手机和平板上均应清晰可点击/输入，不强制安装第三方应用。

**结果页面（随对应训练组实现，不要推迟到最后）**

- 闪电心算（第1、2组）完成后参照 `23-flash-result-summary.png`，展示总用时、最终答案、10个输入数字的顺序回顾与重来/返回。
- 普通算式训练完成后参照 `24-quiz-result-dialog.png`、`25-quiz-answer-review.png`，提供汇总弹窗、逐题结果表、每题用时、总用时、重来/返回，所有统计必须与实际答案记录一致。
- 原参考截图出现部分不进位/不借位的算式，不得覆盖第3～5组的专属约束。

**第二阶段：原参考小程序其他菜单算法**

- 参考 `06-reference-feature-menu.png` 的菜单与本仓库截图，逐题型增加算法；有确切时间的按精确值，缺少证据的标待确认。
- 支持历史记录、导出题目、自定义首数位数/运算符/第二数位数等，但只在符合核心免费要求且不冲突时添加。

**第三阶段：PWA与交付**

- 提供可添加到 iPad/iPhone 主屏幕的图标、manifest和离线缓存方案；不使用收费数据库。
- GitHub Pages部署：提交网站后在仓库Settings → Pages里选择Source并启用。当前仓库资料仅含需求和参考图，**还没有网站**。
- 完成后附测试结果与公开访问链接。页面需原创，不直接复用第三方截图构成用户界面。

## 可接受的技术方案

- 优先纯前端 HTML/CSS/JS + ES Modules 或轻量构建工具。构建产物可直接放置GitHub Pages；不要为了几种算术题引入收费后台。
- 使用可复现的出题算法与本地随机源，校验全组题目的数学约束。避免暴露正确答案在界面上，但可保存在本地状态供核验。
- 训练成绩的个人数据使用浏览器本地存储（注意不同设备不自动同步）；GitHub Pages 不提供私有数据库。
- 数字键盘适配触屏与实体键盘；支持小数点（七组除以2可能需要），答题状态明确。
